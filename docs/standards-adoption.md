## Next stage (when moving from MVP to production)
These practices start to apply if the project becomes production-critical. Re-run `/project-init` in upgrade mode at that point.

- Quality gates for complexity and duplication in CI.
- C4 architecture diagrams (the M8 `ARCHITECTURE.md` is a start).
- Availability targets, a disaster-recovery plan, SLOs, alerting and an incident process.
- SBOM with build provenance, and published patch timelines for vulnerabilities.
- Dynamic security testing (DAST) of the deployed app.
- Feature flags, performance budgets and real-user Core Web Vitals.

Also re-run the setup if the project starts storing data, adds accounts, or if any of GDPR, the EU AI Act or the European Accessibility Act is confirmed to apply.
